# Security Policy

## Supported Versions

Security fixes are applied to the latest published release. Users should update to
the newest GitHub Release before reporting a problem that may already be fixed.

## Reporting a Vulnerability

Please use the repository's private **Security advisories** page:

<https://github.com/ROOT94-MAX/DiscordAITranslator/security/advisories/new>

Include the affected version/build ID, reproduction steps, impact, and any relevant
logs with credentials, message contents, account identifiers, and server identifiers
removed. Please avoid public issues for undisclosed vulnerabilities.

The maintainer will acknowledge a complete report, investigate it, and coordinate a
fix and disclosure timeline through the private advisory.
